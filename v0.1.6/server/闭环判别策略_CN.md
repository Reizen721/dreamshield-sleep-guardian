# v0.1.6 时序融合与事件复核策略

本次实现热像时序证据、按事件调用VLM和环境规则控制，可称为决策层融合，不是已训练的端到端多模态网络或VLA。VLM不能生成可执行空调命令。

## 数据流

热像板 → 电脑温度阵列缓存 → 原本地模型 → 时序窗口 → 事件调度 → 2～4张关键帧VLM核对 → 统一温控策略 → Freenove红外发射 → 环境反馈。

本地观察和VLM分离线程，慢请求期间继续观察、更新环境连续性，但不自动发送。本次未增加OV2640照片上传。

| 参数 | 默认值/含义 |
|---|---|
| 本地推理 | 2秒目标间隔，实际受推理耗时/到帧速度影响 |
| 窗口 | 30秒，确认阈值更大时随之延长 |
| 历史 | 最多120秒、180个实际样本 |
| 连续确认 | 均衡20秒，沿用预设/自定义20～50秒 |
| 时间支持 | 至少80%且最新类别一致；不是准确率 |
| 断流 | 帧间隔或当前帧时效超过6秒，重置确认并撤销资格 |
| 稳定抽查 | 300秒，网页可调60～1800秒 |
| VLM最短间隔 | 全局20秒，同事件疑难/调节前重核对60秒 |
| 失败退避 | 至少60秒，仍需满足触发条件 |
| 复核有效期 | 末张关键帧接收时间起90秒，不从回复时间重新算 |
| 预算 | 每小时60次，进程100次，停止再开不清空进程预算 |

同frame_id不加证据，倒序、新来源、长间断不能累积确认。回放逐片段重置，不编造中间动作。本地部分/大面积未覆盖合并为控制层“未覆盖”；原四类输出、拒判保留。未知段不算肯定支持。

## VLM调用

首次连续证据足够、稳定状态事件变化、持续疑难、稳定场景抽查、调温需要新复核时调用。调温需求使用原有同一策略计算，不引入第二套温控阈值。

选最早保留帧、确认期起点附近、中点附近和最新帧，去重后2～4张。统一18～38℃灰度，不逐帧拉伸。放大不增加80×62信息；时间为服务器接收时间，不代表曝光同步。

不向VLM提供本地预测类别和分数，避免诱导附和。返回逐帧覆盖、变化类型、可比性、证据充分性、依据和局限。无事件前基线不能声称拍到踢被过程。热区不是精确人体分区，热像不能穿透被子。

## 判定与控制

本地明确结论与VLM冲突则不确定；本地拒判允许VLM独立核对。持续未覆盖要求关键帧覆盖确认时长、最后两帧均支持未覆盖，且确认期没有本地覆盖/无人反证。这是稀疏关键帧结合时序的操作性确认，并非证明帧间每一瞬间都未覆盖。

停止、改策略、更换来源、断流、最新本地类别改变都会撤销旧结果。回复到达后再核对最新帧、事件版本与时效，先写日志成功再授予临时资格。

保留三种预设及自定义。均衡室温24～28℃、环境持续45秒、单次1℃、冷却300秒、设定范围24～28℃。持续未覆盖且室温不高于下限+1℃可提出升高制冷设定；偏热时不会因未覆盖自动升温或加强制冷。已处理事件不重复升温，恢复确认、人工接管和结果不明确时的处理仍由原控制器管理。

仅建议与实控规则相同但不发送。云端忙、证据缺失、复核过期、传感器不可用时不新增调节。旧温湿度沿用原受限fallback和时效/来源标记；重复旧样本不伪造趋势。历史环境数据无效，本次未训练温湿度融合网络，也未验证真实节能/舒适收益。

日志记录关键帧ID、本地类别、VLM解释、事件、策略、环境摘要与发射反馈。发射成功不等于空调执行，室温变化也不是执行回执。

## 部署/回退

电脑运行，原模型权重和固件不变；TCN仅研究。新版端口8016、数据目录DreamShieldTemporal016独立。停止新版并退出托盘即可回到原版；勿让两版同时连接热像TCP或控制空调。

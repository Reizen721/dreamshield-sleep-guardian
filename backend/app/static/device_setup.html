等待蓝牙连接

由 ESP32 扫描它能连接的 2.4 GHz 网络，不是电脑的 Wi-Fi 列表。

安全会话就绪后，可扫描附近 Wi-Fi，或手动填写隐藏网络名称。

密码按 UTF-8 字节数校验，空格不会自动删去；本版不支持 64 位十六进制原始密钥。

本版不支持无密码的开放 Wi-Fi。不要把“扫描不到网络”当成“无需密码”。隐藏 SSID 可手动填写；5 GHz 专用网络、登录认证页面和企业认证网络不适用于本次配网。

点击后会清空名称、密码和配网码输入。只有设备明确报告连网并取得地址，才算 Wi-Fi 配网成功；“凭据已发送”不是成功。

开始前，检查这四件事

  1. 电脑具备可用蓝牙

    在 Windows“设置 → 蓝牙和设备”中打开蓝牙。没有蓝牙硬件的电脑需要 USB 蓝牙适配器。

  2. Python 服务已安装 BLE 依赖

    若页面提示依赖缺失，请按项目中文教程安装后重新启动服务器。“依赖已安装”不等于电脑蓝牙硬件已测试。

  3. 开发板运行支持 BLE 配网的固件

    旧固件不会出现配网广播。上传对应固件后，在 USB 串口 115200 发送 p；BLE 名称类似 DreamShield-XXXXXX。

  4. 使用可连接的 2.4 GHz 家庭网络

    可与电脑同处一个路由器网络；避免访客隔离、AP 隔离或需要网页登录的热点。

配网只配置设备网络，不打开 AI、不发送红外或空调指令。请把独立配网码保留在可信范围内。
